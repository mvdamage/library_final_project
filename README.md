# Домашняя библиотека

Приложение на **Python 3** и **PyQt5** для учета личной коллекции книг: добавление, редактирование, удаление, поиск, статистика и выгрузка отчетов в **TXT** и **HTML**. Данные хранятся в локальной базе **SQLite** (`library.db`).

Режим работы — **однопользовательский**: одна копия программы и один файл базы на компьютере.

---

## Возможности

| Функция | Описание |
|--------|----------|
| CRUD | Добавление, изменение и удаление книг |
| Таблица | Пять колонок (без служебного номера в интерфейсе); `id` хранится в данных ячейки |
| Поиск | По названию, автору, жанру и году; без учета регистра; учет **ё/е** |
| Валидация | Обязательные поля, год — 4 цифры, не больше текущего года |
| Дубликаты | Блокировка записи с полным совпадением полей (регистр не важен) |
| Статистика | Общее число книг, разбивка по жанрам и авторам |
| Отчеты | Сохранение списка книг и статистики в `.txt` или `.html` |
| Автотесты | 35 тестов для `database.py` и `reports.py` |

## Структура проекта

```
library_final_project/
  main.py              # Запуск приложения, окна, кнопки, таблица
  database.py          # SQLite: CRUD, поиск, дубликаты, статистика

  tests/
    test_database.py   # 22 теста
```

Модуль **`reports.py`** при разработке оформлялся с использованием ИИ-инструмента (генерация шаблонов отчета); далее код дорабатывался вручную (статистика в HTML, колонки рядом).

## Установка и запуск

1. Откройте терминал и перейдите в папку проекта:

   ```powershell
   cd путь\library_final_project
   ```

2. (Рекомендуется) создайте и активируйте виртуальное окружение:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

3. Установите зависимости:

   ```powershell
   python -m pip install PyQt5
   ```

4. Запустите приложение:

   ```powershell
   python main.py
   ```

При первом запуске в каталоге появится файл **`library.db`**.

## Работа с интерфейсом

### Панель инструментов

- **Новая книга** — форма добавления.
- **Редактировать** — изменить выбранную строку (или двойной щелчок по строке).
- **Удалить** — удалить выбранную книгу (с подтверждением).
- **Статистика** — окно: всего книг, таблицы «По жанрам» и «По авторам».
- **Отчет** — диалог сохранения файла (HTML или TXT).
- **Поиск** — фильтрация таблицы по мере ввода текста.

### Поля книги

| Поле | Обязательное | Примечание |
|------|--------------|------------|
| Название | да | Многострочное поле |
| Том | нет | Пустое значение в БД хранится как `NULL` |
| Автор | да | |
| Год издания | да | Ровно 4 цифры, не больше текущего года |
| Жанр | да | |

При сохранении текстовые поля обрезаются по краям; буквы **ё** при записи в БД приводятся к **е** (единый стиль хранения). Поиск и проверка дубликатов **ё** и **е** считают одинаковыми.

### Отчеты

1. Нажмите **Отчет**.
2. Укажите имя файла и тип: **HTML (*.html)** или **Текст (*.txt)**.
3. Откройте сохраненный файл в браузере или редакторе.

В отчетах таблица всех книг; блок статистики — две таблицы (**жанры** и **авторы**).

## Слой данных (`database.py`)

### Таблица `library`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INTEGER | Первичный ключ |
| `title` | TEXT | Название |
| `volume` | TEXT | Том (может быть `NULL`) |
| `author` | TEXT | Автор |
| `year` | INTEGER | Год |
| `genre` | TEXT | Жанр |

### Основные методы класса `Database`

| Метод | Назначение |
|-------|------------|
| `add_book` | Добавление записи |
| `get_all_books` | Все книги, сортировка по `id` |
| `update_book` / `delete_book` | Изменение и удаление по `id` |
| `search_book` | Поиск с функцией SQLite `py_lower` |
| `is_duplicate_book` | Проверка полного дубликата, параметр `exclude_id` при редактировании |
| `count_books`, `count_by_genre`, `count_by_author` | Статистика |
| `close` | Закрытие соединения |

## Архитектура интерфейса (`main.py`)

| Класс | Роль |
|-------|------|
| `BookDialog` | Форма добавления/редактирования, валидация, проверка дубликата |
| `StatsDialog` | Окно статистики |
| `Library` | Главное окно: таблица, поиск, вызов БД и отчетов |

Идентификатор книги в таблице не отображается: хранится в `Qt.UserRole` у ячейки в колонке «Название». После добавления или правки строка с этой книгой выделяется автоматически.

## Автотесты

Установка pytest (при необходимости, если еще не установлен):

```powershell
python -m pip install pytest
```

Запуск всех тестов:

```powershell
python -m pytest tests -v
```

Тесты используют **временную** базу в каталоге pytest (`tmp_path`), рабочий `library.db` не изменяется.

## Технологии

- Python 3, ООП, модульная структура
- PyQt5 (Qt Widgets, диалоги, таблица, `QFileDialog`)

## Устранение типичных проблем

| Проблема | Решение |
|----------|---------|
| `ModuleNotFoundError: PyQt5` | `python -m pip install PyQt5` |
| `No module named 'database'` при тестах | Запускайте pytest из корня проекта; в проекте есть `pytest.ini` |
| Пустая таблица после копирования проекта | Убедитесь, что `library.db` лежит рядом с `main.py` или добавьте книги заново |
